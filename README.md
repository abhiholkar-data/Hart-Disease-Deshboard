# Hart-Disease-Deshboard
Interactive Power BI dashboard for Heart Disease Analysis. Analyzes patient health data using KPI cards, slicers, DAX, line/column charts and ribbon charts. Explores key factors such as patient status, serum levels, diabetes, age and other health indicators to identify meaningful patterns and insights.
# 📊 Heart Disease Analysis — Power BI

## 📌 Project Overview

An interactive Power BI dashboard created to analyze heart disease patient data and identify important patterns across different health indicators.

## 🛠️ Tools & Technologies

* Power BI
* DAX
* Data Visualization
* Data Analysis

## 📈 Dashboard Features

* KPI Cards
* Interactive Slicers
* Line & Column Charts
* Ribbon Chart
* Patient Status Analysis
* Serum Level Analysis
* Diabetes Analysis
* Age-based Analysis
* Interactive filtering and data exploration

## 🎯 Key Objective

The objective of this project is to transform raw healthcare data into an interactive dashboard that makes patient-related patterns and insights easier to understand.
